\# OpenCV Photo Editor

A simple photo editor built using Python and OpenCV.

\#Repository:

\- https://github.com/bhumika06br/opencv-photo-editor

\## Features

\- Read and display images

\- Image processing using OpenCV

\- Image modifications

\- Save edited images


\## Technologies Used

\- Python

\- OpenCV


\## How to Run

1\. Install OpenCV:pip install opencv-python

2.\. Run the program: python photo\_editor.py


\## Files

\- `photo\_editor.py` - Main Python program

\- `input.png` - Original image

\- `output.jpg` - Edited image
